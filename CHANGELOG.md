# Changelog

## 0.0.6 — 2026-11-14

- Replaced the macro input skin with a bordered multiline preview so complete templates are visible.
- Added short explanations for the template selector, laugh toggle, racial and food fields, and copy action.

## 0.0.5 — 2026-11-14

- Added selectable opposing-player alert sounds and Cheer, Laugh, and Roar emotes, with a preview button.
- Removed the dropdown suffix that looked like a poison or stone rank.
- Kept option labels ASCII-only so the Forever client font does not show replacement glyphs.
- Emote choices perform the selected character emote; raid warning remains the default.

## 0.0.4 — 2026-11-14

- Increased the macro preview area so longer templates are readable.
- Made the repository URL visible in the contact section and added a chat reminder button.
- Separated poison and stone labels into fixed columns and widened the bar to prevent overlap at all size presets.
- Split options into QOL, Macros, Addon Settings, and PvP tabs, with shorter controls inside the panel.
- Replaced non-ASCII punctuation in in-game labels to avoid missing-glyph boxes in the legacy client font.
- Added an optional setting to hide the coating bar in cities and inns.

## 0.0.3 — 2026-11-14

- Added configurable bar lock, saved drag placement, and small/standard/large size presets.
- Changed coating selectors to dropdown menus and narrowed settings controls.
- Added a poison recipe planner that compares required materials with bag counts.
- Added configurable macro previews for stealth, Sap, attack starts, weapon swaps, dagger openers, and cooldowns, with food/racial placeholders and optional laughs.
- Added configurable opponent-player sound alerts by world, battleground, or instance context.
- Added in-game mail feedback details and a copyable repository link.
- Added a Discord announcement workflow for published releases.
- Live-client verification is still required for game API behavior and macro results.

## 0.0.2 — 2026-11-14

- Added a combined Main Hand/Off Hand coating bar with separate poison and stone icons.
- Added independent poison and stone warning controls and a forced-visibility toggle.
- Added Interface → AddOns settings, a minimap button, and per-hand normal/Shift/Ctrl/Alt coating actions.
- Added bag-aware selection of the highest available rank in a chosen poison family.
- Show remaining time in minutes at one minute or more, then seconds below one minute.
- This release needs a live-client check of click-to-apply behavior.

## 0.0.1 — 2026-11-14

Initial public development preview.

- Added the Main Hand and Off Hand coating indicators.
- Added configurable time and charge warning thresholds.
- Added Forever API research and release/install notes.

The initial preview has not been loaded in the live game client. Reagent planning, supply reminders, and the macro builder remain planned work.
